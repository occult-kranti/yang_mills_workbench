# Three-role, two-loop collaboration contract

Use this procedure when the user requests an advisor–skeptic, a forward researcher and a backward researcher for sequential feedback loops. The coordinator serves as advisor–skeptic, with exactly two delegated workers. The requested team count includes the coordinator. Do not spawn nested reviewers that silently exceed it.

1. Write the common action/state/observable/units contract and freeze the starting evidence. Identify algorithmic degrees separately from physical variables and genuine action deformations.
2. Give the forward worker consequences to derive and an independent comparison to implement. Give the backward worker a precise target, all missing premises to expose and a mathematically different verification method.
3. Execute Loop1 and exchange actual objections. Record which participant changed which bound, hypothesis or test. Preserve failures. A preparatory diagram is not evidence that a loop ran.
4. Issue a source-bound Loop1 gate. Choose Loop2 from a concrete unresolved target exposed by Loop1, with acceptance criteria declared before the new computation.
5. Execute Loop2; independently reconstruct its evidence, including normalization and total remainder. Check malformed inputs and evidence admission. A producer's second run is not an independent review.
6. Issue the second gate only after corrections are independently reviewed. Build the shared network from the executed ledger, showing owners, completed gates and planned future work.
7. Report exactly the requested completed loops. Propose the next bounded contract without portraying unexecuted work or the outer unsolved theorem as completed.

Round14 lessons: a source hash records provenance but cannot turn a caller-supplied pass object into authority. Proof admission must rerun evidence or accept only internally issued immutable verified state. Freeze and revalidate the actual rule semantics, not only their identifiers or disk bytes. A finite static state does not determine its physical generator; backward spectral obligations need an explicit state/generator match.

For a finite exponential-Haar deformation, constants and variables must retain their roles. An added coefficient changes the action. A controlled removal bound for bounded finite observables is useful, but it does not automatically extend uniformly in volume or identify a continuum theory.
