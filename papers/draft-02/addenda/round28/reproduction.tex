\section{Reproduction and artifact integrity}
The frozen contracts, producer reports, exact outputs and skeptical gates in \repo{research/round28/} govern each result. Scientific replay is separate from building this manuscript. From the repository root the addendum is built with
\begin{verbatim}
python3 -B papers/round28-addendum/build.py
\end{verbatim}
All ten investigations have source-bound advisor gates and a reviewed chapter here. The final build requires those ten gates and verifies their complete bindings. The explicitly marked intermediate-document mode \repo{--draft} remains available; it includes only admitted chapters and writes solely to its temporary build directory. Neither mode promotes a report to acceptance. Figures are computed from admitted exact evidence; floating-point conversion is only for rendering unless a figure explicitly states a different numerical scope.

The build uses ordinary \LaTeX, Poppler and the installed Python scientific stack. It installs no dependencies. Final publication requires rendering and visually reviewing every page after the last meaningful change. A clean compiler log, text-extraction check or targeted intermediate review does not replace that all-page inspection. The final artifact manifest binds the editable sources, figures, PDF and review record; a separate source manifest binds the admitted reports, outputs and gates. Hash agreement establishes integrity, not mathematical truth or independent experimental confirmation. Draft01 and the Round27 artifact bytes remain unchanged.

\paragraph{Open target.} The admitted homogeneous representation and Wilson results, canonical readout certificates, finite-graph calculations and reference-only bounds retain their separate models and conclusions. Their combination does not supply the missing continuum construction, axioms or physical matching. The scope ledger states each investigation's result, possible application and remaining limitation; later results do not silently rewrite earlier admissions.
