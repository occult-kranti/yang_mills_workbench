\section{Reproduction, review and linked sources}
The mathematical reports remain authoritative for their frozen assumptions, complete-support definitions and detailed controls. This manuscript summarizes them without rewriting the accepted gates or Draft01. Every displayed plot is reconstructed from exact JSON fractions; converting to floating point occurs only after the exact decision, for rendering. This is not a new physical simulation.

From the repository root, replay all three producer pairs into a fresh absolute directory outside the repository:
\begin{verbatim}
python3 -B research/round27/reproduce.py \
  --output /absolute/new/round27-replay
python3 -B research/round27/reproduce.py --optimized \
  --output /absolute/new/round27-optimized
python3 -B papers/round27-addendum/build.py
\end{verbatim}
The first two commands verify source/snapshot bindings and byte-identical fresh outputs. Output directories must not already exist. Optimized mode checks that Python optimization does not disable the controls. They do not constitute formal verification of an operator proof or independent empirical observations. The final command builds the plot and the PDF with the installed Python scientific stack, ordinary \LaTeX\ and Poppler; no dependency download is needed in the authoring environment. It requires all final scoped gates.

The addendum's \repo{manifest.json} binds its source files, final PDF and plots, together with the source gates/reports it summarizes. \repo{pdf-qa.json} records the final PDF hash, page count, text/layout diagnostics and the separate visual review. Temporary page rasters and TeX products are excluded from the source package. The PDF is rendered and visually checked after the final content change. Rebuilding requires repeating that visual review; successful compilation alone is insufficient.

\paragraph{Repository evidence.} Within \repo{research/round27/}, see \repo{contracts/}, the separate \repo{forward/} and \repo{reverse/} reports and exact outputs, \repo{skeptic/}, and \repo{advisor/}.
