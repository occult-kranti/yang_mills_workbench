## Reproduce

Use Python 3.11+ standard library and Node. Outputs must use fresh absolute directories outside this checkout:

```bash
python3 -B research/round26/admission.py --output /absolute/new/round26-normal
python3 -B -O research/round26/admission.py --optimized --output /absolute/new/round26-optimized
python3 -B research/round26/test_admission.py
python3 -B research/round26/build_site.py
```
