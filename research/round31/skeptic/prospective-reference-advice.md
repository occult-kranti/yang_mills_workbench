# Prospective advice on a source-local AQ reference comparison

This is planning advice after initial triage, not execution of a second investigation. No prospective numerical success is admitted.

The inherited coefficient dictionary genuinely admits zero selected coefficients: Round19 A1 specifies |lambda_L|,|lambda_R|<=alpha/2 and |mu_M|<=alpha/8 and explicitly includes zero; I1 and AQ import that reference. Choosing these three coefficients zero makes the reference Haar/pure electric. Retaining nonzero omitted tau leaves a real interacting AQ subfamily. It does **not** produce the uniform Wilson magnetic theory: three selected xy faces in each complete factor still have zero magnetic coefficient. This change from any earlier nonzero triple must be frozen as a new parameter subcase.

A route worth testing after the first gate is the following. The free evolution of a bounded local observable stays supported on its original complete factors, because the reference is an onsite tensor sum. A Duhamel comparison against this free observable can charge only interaction stars meeting that support, rather than the extensive norm of all interactions. In a finite box the difference is controlled through a strongly justified bounded-perturbation identity for the unbounded onsite operator; then the inherited norm volume limit may pass the bound to the AQ dynamics. Retain all seven stars meeting the two-factor Wilson cover and restore physical time from the normalized clock.

The local reset estimate compares the actual state's restriction with the reference product density. Apply it to the actual operator used in the real-time correlation and then account for the mean square. State comparison and dynamical comparison are distinct terms. A nonzero selected triple does not automatically prevent this route, but its reference real-time correlation must itself be evaluated or certified; silently replacing it by the free Wilson formula is invalid.

For a nonnegative ground-centered spectral generator, the scalar Fourier transform of the Poisson/Cauchy kernel maps exp(i r x) to exp(-s|x|)=exp(-s x). This gives a route from real-time correlation control to a Euclidean enclosure. It requires Bochner/weak integration with a finite positive measure, an actual centered spectral statement and a complete time-tail estimate. A bound proportional to |r| cannot simply be integrated over all r against the Cauchy kernel: its absolute first moment diverges. Use a cutoff with paid tail or the exact min(linear, uniform) envelope. Check small/zero coupling continuously and keep any logarithmic term's domain explicit.

At very small but nonzero tau this may certify the actual AQ scalar inside a narrow interval near the exact reference value without computing a finite-volume eigenvector. The deliverable must be named an analytic enclosure for the interacting state; it does not resolve state uniqueness, recover the actual interaction correction, validate cap-level tau=10^-8, or produce all 4097 data nodes unless those claims are separately proved. A conditional sufficient bound failing at larger tau is not an accuracy impossibility theorem.
