# Integration and visual checks

The four statistical/error/scale figures and the two-cube graph were rendered to standalone PNG/SVG and visually inspected. Their legends, labels and plotted points are readable. The graph highlights exactly the four shared-square edges and distinguishes the two five-face disks from the shared face. The scientific plot data remain the recorded exact-certificate endpoints and exact scale rows, rounded only for display.

The first new document-dialog test failed because its mock `closest` method recognized only an exact single selector, whereas the actual delegated event handler uses a combined selector. The test fixture was repaired to model the real selector lookup and element attributes. It then opens the existing shared dialog and verifies escaped document content. This was a test-harness defect, not a mathematical correction or an observed browser failure.

Actual-script Node tests cover eight new routes, historical navigation, source-bound evidence, certificate downloads, outward decimal containment, document events, invalid plot data and unsafe strings. The common local/Pages test verifies the complete published build manifest, project-prefixed downloads and retained calculator/learning/patent views. The localhost smoke test runs both actual Python server configurations and retrieves the current and historical assets.

No real-browser visual layout or keyboard audit was performed. The standalone figures were visually reviewed; browser behavior was tested in a Node VM and over loopback HTTP. These scopes are deliberately separate.
