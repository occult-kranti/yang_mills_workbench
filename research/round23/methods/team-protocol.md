# Round23 independent team protocol

Root is advisor/integrator. Forward and reverse own separate direction directories and derive from the same frozen contract and named inherited inputs; neither reads the current other solution before both submissions are frozen. Skeptic prepares independently, then reads/replays both frozen submissions. A shared source choice in preparation is disclosed in the contract. Independent agents are not independent physical experiments or human peer review.

For each loop write report.md, check.py with --output fresh absolute directory, and deterministic output/results.json, controls.json, source-manifest.json. Results and controls carry loop, direction, status and passed keys; passed marks executed checks, not broad goal success. Manifest inputs bind the report, checker, contract, all contract dependencies, all instruction_inputs and this protocol, plus every nonstandard inherited input actually consulted or imported. Outputs bind results.json and controls.json and any other deterministic scientific output. Freeze submission.json containing the submitted file hashes.

Use explicit runtime exceptions for admission so Python optimization cannot disable gates. Controls must demonstrate meaningful wrong-model discrimination; unchanged valid symmetries remain exceptions. No fixture proves infinite-dimensional completeness. A report gives the model, graph/boundary, state, units, domains, topology, derivation, primary-source reading depth, novelty category, proposed equations, actual conclusion, limitations and next missing premise.

Second loops are selected only after first-loop evidence, skeptical review and advisor decision. Select goals V and W only after all six S/T/U loops. Reviews, repairs, reruns, source reading, skill updates and website work add no research loops. Ten reviewed investigations need not mean ten accepted targets. Never change an already frozen artifact silently; use an explicit addendum or repair inventory.
