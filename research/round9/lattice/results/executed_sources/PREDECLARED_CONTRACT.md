# Bounded SU(2) lattice experiment contract

Declared before any stochastic experiment is run. This is a finite Wilson-measure implementation audit, not a mass-gap calculation.

1. Links are real unit quaternions `q=(q0,q1,q2,q3)` representing `U=q0 I-i q·sigma`. Products use the usual positive cross product. No measured or evolved link is silently normalized or clipped. Normalizing Gaussian vectors to *generate* Haar SU(2) is part of the sampling algorithm.
2. Four periodic lengths are integers at least two. `S=beta sum_(x,mu<nu)(1-scalar(Uplaquette))`; beta is finite and nonnegative. The open staple A runs from x+mu back to x, and the local link contribution is `-beta scalar(U_mu(x) A)`.
3. Left proposals mix Haar SU(2) with axis-isotropic rotations of angle uniform on [-0.6,0.6], with Haar probability 0.2. Both distributions are inversion symmetric. Every link is visited once per sweep; sequential composition preserves the target distribution, although an entire fixed-order sweep need not itself satisfy detailed balance.
4. Run exactly two independently seeded chains (one cold, one hot) for each beta in [0,0.5,2.2], on lengths [2,2,2,2]. Each has 512 warmup sweeps and 2048 measured sweeps, measured every sweep. No tuning, rerun, seed replacement or longer run will be used to rescue a failed statistical comparison. Exact beta-zero independent Haar checks and exact one-plaquette checks are separate experiments.
5. Stochastic outputs are diagnostics, never mathematical certificates. For each observable use batch sizes 16,32,64; primary uncertainty is batch size 64 (32 batches per chain). Report mean, batch standard error, integrated autocorrelation estimate, sample count, and batch-size sensitivity. A 5-standard-error comparison is predeclared only as `consistent`, `flagged`, or `insufficient`, not a proof of convergence. If autocorrelation time exceeds 64/5 sweeps or there are fewer than 20 primary batches, the comparison is `insufficient`. Identically zero beta-zero Ward residual is algebraic/trivial, not a stochastic validation.
6. Compare hot/cold plaquette means using independent-chain standard errors. At nonzero beta test the all-link averaged identity `W=beta^2 |vec(UA)|^2-3 beta scalar(UA)` against zero. At beta zero check the mean of all plaquettes against zero and the mean of squared individual plaquettes against 1/4. These lattice expectations are exact, but their estimators are correlated. No inference to glueball mass, continuum limit or infinite volume is permitted.
7. The independent one-plaquette rejection sampler generates 20,000 IID samples per beta. Its exact normalized partition function is `Z(beta)=2 I1(beta)/beta`, `Z(0)=1`; scalar mean is `I2(beta)/I1(beta)`, with limiting mean zero and variance 1/4 at beta zero. Check mean and second moment using a predeclared 5-standard-error criterion. This is not an exact formula for the interacting 4D lattice.
8. Deterministic checks must reject a run on failure: matrix/quaternion orientation, plaquette orientation, random link full-action difference, gauge invariance, cold action zero, center seam symmetry, inverse proposal reversibility and acceptance ratio, finite/group validity, input validation, empty and NaN statistics. Target absolute tolerances are specified in the test code before execution. Failed and insufficient diagnostics are retained as such.
9. All raw measurements, fixed seeds, runtime versions, hashes and failed diagnostics are saved. Hashes of producer source and this contract are recorded before simulation. This is an agent-produced implementation with an independent agent audit, not peer review.
