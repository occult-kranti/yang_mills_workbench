# Admission and matching lessons

## Portable research evidence

Build admission inventories from actual portable scientific sources and required outputs. Exclude interpreter caches and machine-local environment artifacts when creating a new inventory. An inherited gate that requires an uncommitted cache remains a failed gate; do not silently drop its entry or manufacture its bytes. Preserve the original gate, record the defect and create a separate reviewed inventory with a fresh source replay. A direct calculation can support the mathematics while the complete release gate remains broken.

Check a staged release using files reconstructed from its Git tree. A successful local run may depend on untracked files. Require the expected scientific input set and actual executed implementations, not only whichever entries the producer supplied. Keep inventory creation separate from verification and reject a missing source even if a prior JSON says passed.

## Local stability dictionaries

A diverging global absolute coefficient sum does not invalidate local interaction-norm methods. Specify complete onsite factors, unique link ownership, every crossing plaquette support and the finite coarse interaction range before applying a local-stability theorem. A tail-cell partition and a literal spatial box can select different boundary terms; state the adopted boundary model.

Keep normalized local budgets separate from numerical theorem thresholds. An exact bound on sup_x ||Phi_x|| is not an evaluated source constant c1 or c2. If a theorem states only existence, retain that distinction while attempting a constructive estimate. With a nonzero homogeneous interaction, do not reuse the Hilbert representation of a summable deformation without proving equivalence.

## Physical observables and dynamic identification

For a restricted observable algebra, construct its cyclic Hilbert subspace and prove that dynamics reduces it. A full-algebra GNS identification does not imply equality for the gauge-invariant algebra. Show a specific centered observable has nonzero variance in the actual ground state; a reference-vacuum witness needs an error bound before transfer.

A positive state-dependent mobility can preserve a static measure while changing the generator. Derive its divergence term and transformed operator instead of multiplying an old generator by a variable coefficient. Classify mobility as a dynamics deformation unless independently matched to physical evolution.

For parameter reconstruction, write the forward observable map, compute its rank on the declared domain and supply an explicit inverse or unresolved family. Symmetries may make chosen observables blind at special parameter values. A synthetic inverse test validates the map, not a physical calibration; measured time data and a test of membership in the proposed generator family remain separate premises.
