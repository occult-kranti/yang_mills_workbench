# Fifth-goal advice after AJ2 review — planning only

I favor a bounded **actual homogeneous Wilson signal and energy-control pair**
over a return to canonical readout calibration. AJ1 and AJ2 now refer to the
same locally normal physical state and the same original observable, so this
choice would develop the new result without crossing model classes. This
note selects no goal, proves no new bound, and executes no new checker.

The first proposed investigation should ask for a constructive lower bound on
the actual Wilson variance using AJ1's volume-uniform local reference-energy
control, with an honest obstruction if the chosen certificate is insufficient.
The frozen question would retain R={0,e_z}, its complete factors and endpoint
actions, the fixed selected coefficients, the exact whole-star prescription,
and an explicitly declared symbolic omitted-coupling cap inside tau_*.
Normality alone is deliberately insufficient: AJ2's normal concentrating
states have arbitrarily small variance. Any successful improvement must charge
their energy or another source-qualified property of the actual state.

A contract could compare a finite electric-cutoff certificate with an analytic
concentration estimate. The former must carry the entire omitted tail and the
actual unknown mean through both moments; a positive compressed eigenvalue
alone is insufficient. The latter must justify its Sobolev or uncertainty
inequality on the original link variables and mixed local densities. If the
four-link observable marginal is used computationally, derive that marginal
and its energy bound from the full two-factor state, rather than replacing
the physical completion. Compactness might establish existence of a floor
without evaluating it; that must not be advertised as a constructive numerical
certificate. No particular cutoff, positive floor or coupling value has been
calculated in this planning note.

Only after that first result is reviewed should the second investigation be
chosen. A useful conditional target is a rigorously finite physical first
energy moment of this same Wilson vector and a resulting bounded spectral
window containing certified nonzero overlap. The prospective route is a
finite-volume quadratic-form/Dirichlet calculation for the smooth Wilson
multiplier, followed by an actual source-qualified limit. Retain every kinetic
link term, original endpoint action, selected and omitted interaction, actual
ground centering, and alpha/hbar normalization. Do not claim the required
commutator is bounded simply because W is bounded, or transfer a moment from
an unproved same-representation strong limit. AJ1's tested bounded-local
resolvent topology and a justified moment-limit argument would need to do the
work. This target asks for a form-energy result; an operator-domain or second
moment theorem would be an additional obligation.

If the first certificate is only existential or insufficient, the second
should address its precise quantitative bottleneck instead of assuming a
variance denominator. A successful finite spectral window would still give
neither a threshold eigenatom, an exact lowest overlapping energy, a
real-time decay law, nor a continuum mass. There is no planned extraction of
the unevaluated stability constants.

The main alternative is Tesla's fixed coarse-band readout proposal, read in
`experts/tesla/unknown-clock-planning.md`. It is well bounded and
different from AI4: choose one physical clock and collar using an independently
known prior band, then prove a complete certificate over that band. However,
same-u paired separation would still not distinguish H1(u) from H2(v) for
independently unknown u,v. A second loop would have to address this composite
decision problem, with a rule independent of the unknown parameter, full
errors, and any unresolved region explicitly declared. Timing, phase, scalar
noise and source loading remain obligations; the old parameter-indexed clock
cannot be selected using the true unknown. This would advance the canonical
summable model, with no automatic link to the present homogeneous state.

A certified numerical heat evaluator for the finite AH model remains another
useful engineering question, but it would need its own truncation and time
coverage contract and would not quantify the AJ2 homogeneous vector. I rank
it behind the two options above for the final pair. All eight completed
investigations remain distinct evidence; none supplies missing model or
continuum matching. Source identities and reading scope are recorded beside
the AJ2 comparison. Root should decide after the AJ2 gate.
