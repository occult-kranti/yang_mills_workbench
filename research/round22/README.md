Scripts check arithmetic and evidence integrity; they do not formalize the infinite-dimensional proofs. The reviewers are independent agents, not credentialed human peer reviewers.

## Reproduce the recorded checks

From the repository root, with Python3.11+ and fresh absolute output paths outside the repository checkout:

```bash
python3 -B research/round22/reproduce.py --output /absolute/new/round22-normal
python3 -B -O research/round22/reproduce.py --optimized --output /absolute/new/round22-optimized
python3 -B research/round22/reproduce.py --loops q2 --output /absolute/new/q2-replay
python3 -B research/round22/test_admission.py --loop n1 --output /absolute/new/admission-normal.json
python3 -B -O research/round22/test_admission.py --loop n1 --output /absolute/new/admission-optimized.json
```

The complete runner executes20 producers in each mode and compares every declared output byte with its frozen record. Admission checks reject16 specific mutations, including coherently rebound false claims, missing instruction snapshots, failed nested controls and symlinked inputs. Controls use runtime exceptions so optimized Python cannot disable admission. The original N1 admission implementation is preserved; its separately reviewed repair is explicit. The historical C2 failure and later portable repair remain distinct evidence.

For a contribution's proof, read both reports and the skeptical review as well as running its code. Primary-source records state the precise version, pages, hypotheses and reading depth. Literature constants that were not evaluated remain unevaluated.
