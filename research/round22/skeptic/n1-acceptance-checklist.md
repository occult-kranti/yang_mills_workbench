# N1 independent acceptance checklist

Prepared before inspecting either current N1 submission. This document freezes
the skeptic's review criteria; it does not accept the proposed bound or select
N2. Only inherited work through Round21 and the frozen N1 contract were read.

| Gate | Accept only with | Reject or limit when |
| --- | --- | --- |
| Frozen problem | The canonical summable full-link incomplete tensor product, complete strip/free factor partition, fixed positive alpha/E_star, hbar and spacing, fixed eta in (0,1), q in (0,1). | A homogeneous representation, conditional mobility clock, moving units or q=1 interaction series is substituted. |
| Inherited spectrum | Self-adjoint H_ref; bounded self-adjoint V_q on its common domain; the profile's unique stationary ground, d_q, sigma_q, e_q and gbar. | The dyadic numerical gap or an unrelated representation is imported. |
| Heisenberg identity | Derive the equality of the contract's shifted matrix element and a ground-state expectation of A* times the correct signed Heisenberg evolution of B. | Scalar energy is removed from the raw unshifted matrix element without using stationarity. |
| Strong integral | Give a bounded interaction-picture/cocycle proof, or a comparably complete approximation argument, valid for every Hilbert vector. Show the integrand is strongly continuous, uniformly norm bounded on the integration interval, and its integral defines a bounded operator. | A formal derivative contains H_ref B psi for arbitrary bounded B; norm differentiability is assumed from strong continuity; or a Banach-space norm integral is asserted without its hypotheses. |
| Norm estimate | Justify taking the operator supremum after a uniform vector-integral bound. Keep the factor 2 in the local commutator and the factor 1/hbar. | A fixed-vector convergence theorem is promoted to an operator-norm bound, or no uniform estimate exists. |
| Reference locality | Prove exact complete-factor support preservation for every real reference time by tensor factorization. Count all omitted faces incident to every link of the finite factor cover, once each. | Only displayed Wilson edges are retained after a general within-strip evolution. |
| Complex centering | Retain omega(A*) = conjugate(omega(A)); bound both mean-product differences and the uncentered state change. The coefficient six is sufficient, not automatically optimal. | Either mean cost or conjugation is lost. |
| All real times | Use oriented integrals or an explicit negative-time reduction; cover t=0. | Only positive t is proved while the claim quantifies over all real t. |
| Growing windows | First prove the operator comparison, then substitute the fixed physical T_q into every term and derive exact asymptotic constants. | A power count is used as proof of the operator estimate; eta or support changes silently. |
| Endpoint | Separate a nonvanishing upper certificate from an actual nonconvergence result. Record trivial/commuting or empty-support exceptions precisely. | A positive upper bound is described as a positive error lower bound. |
| Domain control | Exhibit an actual bounded operator taking a domain vector outside D(H_ref), at least in a discriminating abstract model, with an infinite-series proof. | A finite matrix fixture is called a domain counterexample or treated as an infinite-dimensional proof. |
| Other controls | Exact or controlled complex scalar-addition invariance, scalar-Hamiltonian-shift cancellation, full-support count, and a wrong comparison rejected for a concrete reason. | A control just repeats the implementation or has no discriminating output. |
| Admission | Both frozen complete reports/checkers; actual-source manifests; fresh ordinary and optimized output; explicit exceptions; no cross-import; inspect expected source and output completeness. | A stored passed field or hashes alone replace replay; optional untracked dependencies enter admission. |
| Contribution | Established operator method applied to the declared model; scoped project constants and sufficient windows; novelty unverified. | A new universal law, physical clock, homogeneous limit or continuum Yang–Mills theorem is inferred. |

The constant norm of V_q does not obstruct a local Heisenberg norm estimate.
Conversely, success for each fixed local B does not imply convergence uniformly
over the full unit ball of the global observable algebra. Any claim of that
stronger kind requires a separate argument.

The source map is in `n1-primary-source-map.json`. Its checked strong-integral
and interaction-picture results concern operator topology, not this model's
profile constants. The model calculation still needs a complete written proof.
