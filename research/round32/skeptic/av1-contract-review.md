# AV1 contract review (skeptic, pre-comparison)

**Standing.** I wrote this review from the frozen `contracts/av1.json` before reading either AV1 producer. I am a model-agent skeptic with correlated ancestry, not a human peer reviewer. Human author: Hruday N M (BUNZEEY).

**Verdict.** The contract can be executed as written. `av1_check.py` executes all 25 control ids, derives 49/15/82/10 from the I1 table and I1 geometry, and evaluates both tiers at both signs plus the 10^-10 scaling control. My previews give D_ii ~ 1.3612e-8 and D_i ~ 2.3680e-5, so the verdict will turn on whether the proofs are complete, not on margins. None of the points below blocks production. Each is a latitude that a producer could exploit, and the review will hold producers to the reading given here.

1. **Rational reverse constant.** Item 3's constant 2eps/sqrt(1+eps^2) is irrational, while items 4-5 demand exact rationals. A directed rational bound is required, for example 2eps, or a comparison by squaring. A decimal alone fails `exact_arithmetic_admission`.
2. **Several tier-(ii) numbers.** Item 5 allows a triangle bound (49|tau|/144), a grouped value ((11+3sqrt2+2sqrt3+2sqrt10)|tau|/144) and "a sharper directed form"; item 4 allows "optionally iterated". Each number needs its own label. The value tested against 4/10^7 must be the one the gate will bind (`av1_tier_bound` in AV2), and it must be chosen before the comparison.
3. **Unstated a-priori ball.** The self-consistent step t <= t_1/(1-352J) needs t <= R (the AM2 ball) and the convexity bound G(t)-16 <= tG'(t) <= tG'(R). The contract does not say this, so producers must.
4. **Two meanings of t.** eps <= 2t+t^2 is stated with the global t=||c||_a. Only the sums over the sites of R enter eps, but the remainder needs the global anchored norm (`face_count_all_sites`). An 82-face refinement of eps is not forbidden, but it is acceptable only if it is labelled and the remainder is charged as 2*352Jt.
5. **Cutoff space.** Item 6 is adequate if the uniform cutoff gap and E_n >= E are used. Producers must also note that in the cutoff space the first-order vector is Q_n c^(1), because Q_n commutes with H_0. Citing AM2 §6 alone does not move vectors.
6. **Both signs.** Every AV1 bound depends only on |tau|, so the -10^-8 evaluation is a replay of the same formula, not a second confirmation. It still has to be executed.
7. **Error-term ledger.** `error_terms_itemized` lists onsite_cutoff_vector and arithmetic. In this bound they cost exactly zero, since cutoff removal passes the bound through a closed ball and the checker uses exact rationals. They must be entered as zero with the proof or as not_applicable with a reason, never omitted. Straddling and two_creation sit inside eps and must be shown separately.
8. **Enforcing item 11.** A "hard-coded count" can be rejected only by reading the code path. I will accept a count only if it is derived from the snapshotted I1 table (or from I1.1 and I1.4) and then compared with the contract. A literal 49 compared with a literal 49 is rejected.
9. **Premise isolation.** `shared_premises` (hence the reverse inputs) includes `selection-av1.md`, which already states the product-ordering mechanism and where the normalization trap lies. So "derive the trap before exchange" (item 3) means writing one's own derivation and fixture, not discovering the trap. Independence is limited to the list in `premise_note`, and the shared panel premise must be acknowledged.
10. **N >= 2.** Item 1's N >= 2 is harmless. The bound holds for every N with R contained in Lambda_N, and N >= 2 is where all seven incident stars and all 82 faces are present (49 faces at N=1).
11. **Claim flags.** Item 9's six flags are the minimum. I recommend adding uniqueness_claim, whole_sequence_convergence_claim and rate_in_N_claim as false, because item 7 excludes each of these statements.
12. **No shift claim.** Item 8's |omega(W)| <= D must not be accompanied by any sign or 1/144 statement; both are excluded and belong to AW1. The claims |omega(W^2)-1/4| <= D/2 and m^2 <= D^2 need W^2 to be an effect and m^2 to be charged, never assumed zero.
