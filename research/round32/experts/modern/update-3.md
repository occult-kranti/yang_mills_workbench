**The one-inequality difference between the two `D'_ii` values.** Both use the same `t_1'=52|tau|/144`, `T'`, `rho'`, `T'^2`. **Transfer, proved not cited.** Route B ties every face's coefficient to `tau` uniformly, selected faces included (`kappa=tau` throughout), so `U_E H_N(tau)U_E^*=H_N(-tau)` holds exactly in every box and cutoff — AW1's "`kappa=0` only" restriction is not an obstruction here, it never arises, because flipping `tau` flips the model's own `kappa` in lockstep. This is a different reason for the same conclusion, and both producers derive it from the oddness of `E` on every plaquette (selected faces included), not merely assert it by analogy to AW1.

**What `K_2` in the uniform model would still need.** Route B's own `T'`, `rho'` are proved, but the full second-order remainder needs: the straddling/two-creation/density terms re-enumerated with route B's enlarged first-order creation set (`c_0`, `c_{e_z}` are now nonzero at first order, unlike AW1's zero-selected case); a route-B analogue of the ~36-single-site-faces-per-`R`-site accounting AW1 used for its `K_2^+`; and a pinned pair term `T'^2` in the producer checkers (N5 shows it currently runs silently if dropped).
