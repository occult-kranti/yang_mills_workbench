## 3. Rules for the next round

1. `freeze_contract.py` refuses to freeze a contract if any string value contains an angle-bracket placeholder span -- a `<...>` span containing whitespace, a `|`, or the literal text `e.g.` -- using the same detector `assistant-4` built and validated on AZ1/AZ2, so that math notation such as `<=` or `<W>` is never misflagged while `<preceding gate>` and `<declared, e.g. 3/2 and 2 with certified tail>` always are.
2. `freeze_contract.py` refuses to freeze a contract whose `required` items cite "the mandatory sentence template" (or a recorded synonym) unless `preregistration.mandatory_sentence_template` is present and non-empty.
3. `freeze_contract.py` refuses to freeze a finite-model contract (`model_is_finite_graph:true`, or a `model_id` of the form `FG(...)`) unless its `parameters`/`model` text names every coupling of the Hamiltonian term by term -- every face or link coefficient, `alpha`, `rho`, and every `lambda_i` -- with an explicit value or an explicit "shared with `lambda_j`" statement, so no coupling is left to an inherited library default or a parenthetical that reads two ways.
4. `freeze_contract.py` refuses to freeze a contract whose `state_provenance`, `clock`, or `error_terms_itemized` entries are byte-identical to another loop's contract unless the two loops share the same declared model family, so a finite-graph or continuum-trajectory loop cannot silently inherit a Z^3-loop's vocabulary.
5. `freeze_contract.py` refuses to freeze a `statement+skeptic` contract whose subject is an already-admitted constant unless `preregistration.target.note` states plainly whether the target is a feasibility/format check or a blind discriminating threshold.
6. Every forbidden/required-phrase scanner treats a contract's `mandatory_sentence_template` string as one quoted literal excluded from the scan, and scans every other sentence whole-sentence and negation-aware (an explicit negation frame in the same clause, not a bare "not" anywhere in the surrounding text), exactly as the AZ1 skeptic's and producer's scanners already implement.
7. Once a contract carries `preregistration.mandatory_sentence_template`, the reviewing gate's `accepted`/`decision` text must quote that template as one uninterrupted span (elaboration placed only before or after the quotation, never spliced inside it), checked by the same normalize-and-match routine `assistant-4` and `assistant-5` built, so neither the AY1/AY2 gap (template absent entirely) nor the AZ1 gap (template present but broken by an inserted clause) can recur.
8. A contract whose `selected_after` gate does not yet exist at the contract's own freeze time (two loops frozen in the same commit) states this explicitly in a `selected_after_note` field ("frozen in the same commit as its predecessor; gate not yet produced"), so a future auditor does not need to reconstruct commit timestamps to distinguish it from an unfilled placeholder.
9. A final-integration script, run once at round close, checks across every contract from AV1 onward that any field two or more producers/skeptic/gate export under the same name (`states_compared`, `region`, `topology`, `closeness_order`, and any future per-topic value field) is byte-identical among them, and records every disagreement without blocking on it.
10. Before a second producer in the same round invents a new `tier` label, the contract vocabulary a `tier` name is drawn from is closed the same way `sub_labels_allowed` already closes the sub-label vocabulary.
