## Advisor technical observations for the panel to test (not admitted)

1. **Square root is the bottleneck, and AM2 may remove it.** Any variational energy bound gives amplitude ~sqrt(tau). AM2's creation expansion describes the finite-volume ground state itself with anchored coefficient norm O(J)=O(tau), uniformly in volume. For a local observable A supported in the cover R, only creations meeting R enter <Omega_tau, A Omega_tau>; an explicit O(tau) bound |omega_tau(W)|<=c_1|tau| and |omega_tau(W^2)-1/4|<=c_2|tau| with computed c_1,c_2 looks derivable (the roadmap's own "proposed_first_loop_test" for the cap goal). Obstacles: e^{-C} is not unitary, the normalization <psi,psi> and the annihilation adjoint must be handled with the same anchored norm; passage to the AQ subsequential state needs local trace-norm convergence only.
2. **Even with an O(tau) state bound, the AT4 dynamics term has a floor at the cap.** Cost (k s/pi) log(1+L^2/s^2) + (1/2+D/2)(2s/(pi L)) at tau=10^-8, s=1 is minimized near L~1/(2k)~4x10^6 and evaluates to ~1.2–1.3x10^-6, slightly above 10^-6. So the cap goal needs either a sharper real-time comparison (e.g. using the interacting gap or a second-order/commutator structure), a Euclidean-side argument, or an honest, explicitly negotiated target (e.g. 2x10^-6 or a different s). The panel should decide which, prospectively.
3. **An interaction shift cannot be resolved by any O(tau)-error method at first order**, because the shift is itself O(tau). Two honest routes: (a) an exact finite-graph model (finite plaquette graph, representation cutoff with certified tail as in Rounds10–11) where exact rational/interval linear algebra can certify the sign and size of the shift at moderate tau, clearly labelled as a different, finite model; (b) a second-order (O(tau^2) error) expansion in the AM2 framework with the first-order coefficient computed exactly. Route (a) is executable; route (b) is a derivation target.
4. **Uniform Hamiltonian**: setting the selected triple to the uniform value alpha*tau/24 for each selected face keeps the model inside the admitted coefficient box for tiny tau. A pure-electric (Haar) reference with a reset budget charging every selected and omitted term incident to R gives a certified datum for the uniform Kogut–Susskind model at some small tau, with the same sqrt bottleneck; the exact incidence count of selected faces meeting R must be derived. AM2's gap proof must be re-checked for nonzero selected terms (its h_x has selected potential inside, so the reference vacuum is not Haar; the reset budget then differs).
5. **Open-source verification tools available in this session**: python-flint 0.9 (Arb ball arithmetic, exact fmpq), mpmath (interval arithmetic mpmath.iv), sympy, numpy/scipy, matplotlib (figures for experiment/lattice setups).
