This is an integration and dependency-admission review after the six accepted scientific loops, not a seventh physics experiment. The existing search core is byte-identical to the previously audited core; its finite-rule-library exhaustive tests were not repeated.

The review reads `proof_routes.py`, `proof_inputs.json`, `replay_evidence.py`, `reproduce.py`, the gate verifier, saved proof results and the next roadmap. The source inventory binds 158 files. Every library batch admission copies those exact bytes into a new temporary directory and starts a separate Python process that reruns all six independent scientific checks and all six independent producer comparisons. The acceptance is therefore based on fresh arithmetic and comparison, not a supplied status object or a source hash alone.

The independent reviewer reconstructs the full set of eighteen libraries after fresh admission and compares them to the saved report. An independent forward closure check finds six derivable finite-result routes, nine deliberately blocked premise withdrawals and three open targets. For each successful route, the saved search contains actual forward and backward events and a meeting whose backward obligations are included in the forward fact set. The first meeting's ordered certificate is checked separately from the final ordered proof and its cost. The finite dependency certificates remain ordinary reviewed mathematical implications under declared assumptions; they are not a proof-assistant kernel or a complete Yang–Mills construction.

The nine withdrawal controls remove exactly one required premise while preserving the same rule set. They include the local check, sparse check, common physical scale, disjoint link support, basic trial check, adjoint check, explicit endpoint coupling/amplitude, graph/projector check and weighted conditional check. The finite endpoint statement binds both λ/α=12/43 and η=3/3817. The Haar kernel is explicitly a zero-central-coupling result; nonzero-coupling contrast requires its separate C2 gate.

## A semantic defect found and repaired

The initial U1 rule would have derived a dense uniform physical gap from the rotor contract, a local overlap estimate and the common energy scale. Its overlap premise only stated that an explicit local estimate included the vacuum-offdiagonal term. That statement did not supply either an applicable stability implication or a fulfilled smallness condition. The rule was too weak for future use even though the actual route was blocked because its local premise was open.

The advisor repaired U1 by adding two separate open premises: `applicable_rotor_stability`, which requires a proved implication with the correct rotor, domain, range and overlap hypotheses and explicit constants; and `dense_coupling_smallness`, which requires the actual dense family to satisfy its numerical conditions uniformly. Neither is seeded as a fact. The original source, original eighteen-route report and advisor finding are retained in `history/`. This correction changes future dependency requirements; it does not alter any of the six accepted scientific gates or establish the dense theorem.

## Discriminating software checks

The bounded review rejects a forged external passed object, an empty or incomplete frozen-byte inventory, changed arithmetic bytes, missing files, symlink substitution, changed on-disk inventory and changes to an adapter after it is loaded. It separately launches the pinned replay executable against deliberately forged final contrast data: the independent coefficient comparison rejects the altered result even when bypassing the outer hash admission for this control.

All five semantic collections are guarded against in-memory changes. Tests inject open stability premises into the initial hypotheses, promote the endpoint conclusion to a premise, add a fake Yang–Mills gate, remove an open smallness obligation, weaken the common-scale statement, alter the fixed trial amplitude and inject a rule from the conditional kernel to the continuum claim. They are rejected before admission. Ordered proof controls remove a needed step, change a conclusion and use a Boolean cost. A complete valid node schema with an extra hidden endpoint assumption is also rejected by the already-audited library validator.

The portable reproducer is exercised in optimized independent-only mode from an unrelated working directory. It reruns twelve programs and compares their full semantic outputs to the frozen accepted results. Existing output directories and destinations inside the accepted source tree are rejected. The root's separate ordinary all-role reproduction complements this scoped reproducer check.

The finalized review contains 62 named checks. Ordinary and optimized review executions repeat these same checks and are counted once. Source hashes in the executable results are relative to the Round17 directory so the acceptance record does not depend on the original scratch path. No credential or external publication operation is performed by this review.

## Remaining limits and next roadmap

The sparse family needs its support and common-scale assumptions; the finite two-cube trial does not prove a dense volume-uniform theorem; the central conditional integral does not integrate the surrounding link measure. The dense theorem, full bulk contraction and four-dimensional construction remain blocked. The new roadmap retains the required local theorem, full complement spectrum and admissible joint-Gram obligations. The brief separate `roadmap-review.md` records the independent feasibility critique without executing another scientific loop.
